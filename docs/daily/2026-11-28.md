# 2026-11-28

The sixth phase: four lanes and a coordinator slimmed down the study log screens, moved the study amount to chapters and sections finished, set one daily goal and added registering a textbook from a store link. It follows the runs in [2026-11-23](2026-11-23.md) and [2026-11-24](2026-11-24.md). Each lane ran the cycle the lane file sets: branch, implementation with tests and a change record, `npm run check` and the standards check, PR, self-review rounds posted as PR comments, green CI on the final head, `pr merge --merge --match-head-commit`. This time merges to `main` are deployed by the server's autodeploy after CI; lanes never deployed by hand.

Epic #469 (chapters, sections and the 2-hour goal):

- **#475 Difficult parts removed from study logs (PR #486).** Migration 039 drops the column. **#476** the Memo box is much larger, limit 50000 characters (PR #490).
- **#479 One 2-hour daily goal (PR #485).** `GET /api/stats/goal` returns today's minutes against a fixed 120, the rate and the streak; the weekly goal form and `PUT` are gone. - **#480 Chapters and sections finished per study log (PR #495)** and **#481 the Dashboard, Week and 12 weeks show them instead of study time (PR #502).** A new `study_log_contents` table (migration 042, with a backfill from each log's linked entry) and `GET /api/stats/finished-contents`. An entry counts once, on the date of the first done log that finished it. **#503** leftover study-time wording reworded and the two unused endpoints (`/api/stats/study-time`, `/api/stats/heatmap`) removed (PR #505).

Epic #470:

- **#482 Textbook from a Yes24 or Kyobo link (PR #493).** `POST /api/textbooks/from-link` fetches an allow-listed https page (redirects checked host by host, 10 s, 1.5 MB), sends a capped digest to Claude through `callClaude` (feature `textbook-link`) and returns title, author and edition without saving. The form fills in; the person fixes it and registers. `docs/changes/482-textbook-from-link.md` records the robots.txt reading. A CodeQL alert on a hand-written tag strip was fixed in the same PR.

## Checked and not checked

- Every PR was merged on green `ci / verify`, `ci / e2e`, Docker build and CodeQL on its final head. Each lane's `npm run check` and `node .standards/check.mjs` results are in its PR.
- The DB integration tests (daily goal, finished contents, the drop migrations) ran in CI only: no lane had a local `study_test` database.

A live probe with guessed product IDs was inconclusive (Yes24 redirected an unknown ID to its notice page, Kyobo answered an empty 200); `robots.txt` of both stores allows the product pages.

- Known gaps: the paste-the-page-text fallback for #482 is not built; at 360px width the calendar cells are about 41px wide (#500 fixed 390px).
