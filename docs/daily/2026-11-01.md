## 확인하지 못한 것

BIOS의 SVM Mode가 꺼져 있어 Docker가 실행되지 않는다. `docker compose run … api node dist/migrate.js`와 바꾼 DB 헬스체크는 실제로 돌려 보지 못했다. 확인 항목은 `docs/next-steps/README.md`에 있다.
