## 에이전트가 정한 기준

이슈에 없어 에이전트가 정했고, `docs/decisions/schedule-rules.md` 4~7장에 적었다. 사용자가 아직 확인하지 않았다.

- 일정은 만든 뒤 이름만 고친다. 시작일은 오늘 이후, 기간은 366일 이하, 종료일은 내년 말까지이다.
- 지난 날짜의 항목을 완료 취소하면 그 항목만 오늘로 옮긴다.
- 진행률은 끝낸 항목의 목표 시간 ÷ 전체 목표 시간이다.
- 완료한 장은 그 장이나 아래 절에 완료한 학습 기록이 있는 장이다.
- 달성률과 준수율은 처음 계획한 날짜로 센다. 첫날만 놓치고 이후 매일 끝내도 준수율이 0%까지 떨어질 수 있다.

## 예외로 둔 것

`minimatch` 11.0.3과 `@isaacs/nonrecursive-glob-match` 1.0.3은 게시 후 14일이 지나지 않았다. 사용자가 안내받고 직접 설치했다. ESLint 계열이 요구하는 `^10`을 넘겨 강제하므로, 11을 공식 지원하면 override를 지운다.

## 확인하지 못한 것

- BIOS의 SVM Mode가 꺼져 있어 Docker가 실행되지 않는다. `docker compose run … api node dist/migrate.js`와 바꾼 DB 헬스체크는 실제로 돌려 보지 못했다. 앱 DB를 띄우지 못해 마이그레이션은 테스트 DB에만 적용했다.
- API 키가 없어 실제 공휴일 API를 호출하지 못했다. 일정 화면의 브라우저 확인은 테스트 DB에 공휴일을 임시로 넣어 진행했고, 자동 밀기는 항목 날짜를 과거로 당겨 재현했다.
- 프런트 테스트의 간헐적 시간 초과는 원인을 측정하지 않았다(#160).

확인 항목은 `docs/next-steps/README.md`에 있다.
