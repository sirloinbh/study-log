## 로컬 환경

- 사용자 단계에서 끝난 항목: Windows 재부팅, `npm ci --ignore-scripts`로 공유 패키지 설치.
- WSL 3.0.3과 Docker Desktop을 설치했다. BIOS의 SVM Mode가 꺼져 있어 Docker는 아직 실행되지 않는다. 사용자가 나중에 켜기로 했다.
- 테스트 DB에 마이그레이션 012까지 적용했다.
- 원격 이력이 다시 쓰여 어긋난 로컬 브랜치 11개를 사용자 승인으로 지웠다.
